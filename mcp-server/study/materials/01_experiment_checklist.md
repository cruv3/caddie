# Experiment Checkliste

## Pre-Trial Check

- [ ] Device geladen (>80%)
- [ ] Study-App installiert
- [ ] Banking-App installiert
- [ ] Study-App im Vordergrund
- [ ] Screen-off Modus konfiguriert (falls zutreffend)
- [ ] Participant ID notiert
- [ ] Session ID notiert

## Post-Trial Check

- [ ] Alle Events geloggt (events.jsonl existiert)
- [ ] Summary JSON geschrieben
- [ ] Screenshot-Evidence gespeichert
- [ ] Participant Consent protokolliert
- [ ] TAM-Fragebogen ausgehändigt

## Post-Experiment Check

- [ ] Alle Tasks abgeschlossen
- [ ] Alle Conditionen durchlaufen
- [ ] Pre/Post-Messungen durchgeführt
- [ ] Interview-Notizen gemacht
- [ ] Data exported (study-data/ verpackt)
