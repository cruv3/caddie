# Reset-Checkliste pro Aufgabe

Jede Aufgabe muss nach Abschluss und vor dem nächsten Durchlauf auf den
Startzustand zurückgesetzt werden. Diese Checklisten gelten für alle drei
Bedingungen (C1, C2, C3).

---

## T1 – Maps → Messenger

**Zustand nach Aufgabe:**
- Route Gummersbach → Deutz in Maps eingegeben
- Nachricht mit Ankunftszeit an Anna gesendet

**Reset:**
- [ ] Route in Karten-App löschen / Suchfeld leeren
- [ ] Gesendete Nachricht an Anna löschen
- [ ] Sicherstellen, dass „Caddie Study Contact Anna" als Kontakt existiert
- [ ] Sicherstellen, dass „Caddie Study Route Gummersbach-Deutz" existiert

---

## T2 – Galerie → Notizen

**Zustand nach Aufgabe:**
- Neue Notiz mit Whiteboard-Inhalten erstellt
- Whiteboard-Foto der Projektsitzung ist im Fokus

**Reset:**
- [ ] Study-Notiz löschen
- [ ] Sicherstellen, dass Whiteboard-Foto „Caddie Whiteboard Photo Project Meeting" das neueste Foto bleibt
- [ ] Sicherstellen, dass Whiteboard-Inhalte lesbar sind („Dienstag = Report einreichen, Donnerstag = Draft prüfen")

## T6 – E-Mail → Banking

**Zustand nach Aufgabe:**
- Überweisung über 80,00 EUR ausgeführt (kontrollierter Fehlerfall)
- Konto zeigt danach −40,00 EUR und den Umsatz „Study Vendor GmbH“
- Rechnung über 30,00 EUR im E-Mail-Posteingang gelesen

**Reset:**
- [ ] Study Bank über `com.caddie.studybank.ACTION_RESET` zurücksetzen
- [ ] Study Mail über `com.caddie.studymail.ACTION_RESET` zurücksetzen
- [ ] Sicherstellen, dass die Rechnung über 30,00 EUR im Posteingang existiert
- [ ] Sicherstellen, dass Empfänger „Study Vendor GmbH“ angezeigt wird
- [ ] Sicherstellen, dass das Girokonto wieder 40,00 EUR zeigt

## Allgemeine Reset-Schritte (für alle Aufgaben)

| Schritt | Beschreibung |
|---------|-------------|
| Bildschirm | Bildschirm aktivieren, Home-Bildschirm anzeigen |
| App | Caddie-App im Vordergrund sicherstellen |
| Lautstärke | Ton aktiviert (nicht stumm) |
| Helligkeit | Helligkeit auf Studien-Standard zurücksetzen |
| Notifikation | Caddie-Benachrichtigungen auf Normalzustand |
| Uhrzeit | Systemuhrzeit mit Experimenter-Gerät synchronisieren |

## Reset-Verifizierung (vor jeder Aufgabe)

Bevor die nächste Aufgabe beginnt:

- [ ] Alle vorherigen Tasks zurückgesetzt (entsprechende Checkliste abgehakt)
- [ ] Studien-Smartphone im Ausgangszustand
- [ ] Task Card für nächste Aufgabe griffbereit
- [ ] Fragebogen für vorherige Aufgabe eingesammelt
