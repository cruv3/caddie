# Study Paper Materials

This directory contains paper materials for the Caddie Shared Autonomy study:

| File | Description |
|------|-------------|
| `01_experiment_checklist.md` | Pre/post-trial and post-experiment checklists |
| `02_consent_form.md` | Informed consent form (German) |
| `03_task_cards.md` | Task descriptions and condition mapping |
| `04_tam_questionnaire.md` | TAM questionnaire (Perceived Usefulness, Ease of Use, Trust, Control, Transparency, Satisfaction) |

## Usage

1. Print materials before each study session
2. Follow the experiment checklist step by step
3. Have participants sign the consent form before starting
4. Distribute task cards as reference during the session
5. Administer TAM questionnaire after all tasks are completed
6. Export study data and package materials for analysis
