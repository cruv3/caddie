## Studie: Shared Autonomy in LLM-basierten Smartphone-Agenten

### Hauptuntersuchende:
Andreas [Nachname]
Technische Hochschule Köln (TH Köln)

### Beschreibung:
Sie nehmen an einer Studie teil, die die Zusammenarbeit zwischen einem
menschlichen Nutzer und einem LLM-basierten Smartphone-Agenten untersucht.
Der Agent führt Aufgaben auf Ihrem Smartphone aus, während Sie die
Ausführung visuell überwachen und eingreifen können.

### Dauer:
ca. 60–75 Minuten

### procedures:
1. Sie führen 18 verschiedene Aufgaben auf Ihrem Smartphone aus
2. Der Agent führt diese Aufgaben automatisch aus
3. Sie können in drei verschiedenen Bedingungen (C1, C2, C3) eingreifen
4. Teilweise Aufgaben werden im Screen-off-Modus durchgeführt
5. Screenshots und Touch-Ereignisse werden gespeichert

### Risiken:
- Minimale kognitive Belastung durch Multitasking (Überwachen + Bestätigen)
- Mögliche Verzögerung der Aufgabenbearbeitung durch Overlay-UI
- Kein signifikantes Sicherheitsrisiko

### Vorteile:
- Kompensation: 10 € pro Teilnahme
- Einblick in die Funktionsweise von KI-Agenten
- Aktiver Einfluss auf die Agent-Ausführung

### Datenschutz:
- Alle Daten werden lokal auf dem Gerät gespeichert
- Export als JSONL/JSON-Dateien
- Screenshots enthalten keine privaten Daten
- Participants können nach Abschluss alle Daten löschen
