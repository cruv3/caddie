## TL;DR (my words, after reading)

Argues pre-LLM transparency tools (feature attribution, model cards) don't transfer cleanly to generative agents. Maps a research roadmap across four pillars: model reporting, evaluation, explanations, and uncertainty communication — each re-framed for LLMs.
