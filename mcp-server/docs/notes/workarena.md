## TL;DR (my words, after reading)

33 (later expanded to ~600 in L1–L3) enterprise tasks on a live ServiceNow instance — list filtering, form filling, dashboard queries. Ships BrowserGym, a reusable environment API consolidating WebArena/VWA/Mind2Web/WorkArena under one interface.
