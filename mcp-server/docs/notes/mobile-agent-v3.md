## TL;DR (my words, after reading)

Introduces GUI-Owl, a native end-to-end foundation GUI agent trained with a self-evolving trajectory pipeline across Android/Ubuntu/macOS/Windows, plus a four-agent framework. Reaches 73.3 on AndroidWorld.
