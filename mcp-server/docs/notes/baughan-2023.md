## TL;DR (my words, after reading)

Crowdsourced 199 real voice-assistant failures, classified them into 12 sources, then ran interviews/surveys to see how failures shape trust. Finds that "overcapturing" (assistant transcribing more than the user intended) is uniquely corrosive to trust, while low-stakes tasks (e.g. music) help users rebuild confidence.

## Direct quotes
