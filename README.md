# LLMSmartphone

> Master's thesis Android app exploring UI abstraction layers for LLM-based smartphone agents (HCI focus). Successor to V1, now built around an MCP-server architecture for agent-device communication.

## Status

Active development. **Thesis not yet officially registered** — scope and research questions may evolve after further discussion with supervisor.

## Layout

- `app/` — Android (Kotlin) UI + Accessibility Service
- `mcp-server/` — Python MCP server providing skills the on-device agent uses (separate Python project with its own deps)
- `docs/` — design + research notes (accessibility, agent orchestrator, MCP smartphone research)
